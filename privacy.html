Privacy Policy

Last updated: March 27, 2026

Focus Nudge is a Chrome extension that helps you stay focused by displaying gentle reminders on distracting websites.

Data Collection

Focus Nudge does not collect, store, or transmit any personal data. Specifically:

  • No browsing history is collected or shared.
  • No analytics or tracking scripts are used.
  • No cookies are set.
  • No accounts or sign-ups are required.

Local Storage

Your settings (enabled sites, nudge interval, streak count, and license key) are saved locally in your browser using Chrome's built-in storage API (chrome.storage.sync). This data syncs across your own Chrome profile but is never sent to us or any third party.

Network Requests

The only network request the extension makes is to the Gumroad API (api.gumroad.com) when you manually enter a Pro license key to verify it. This request sends only the license key you typed — no personal or browsing data is included.

Permissions

The extension requests permissions (tabs, alarms, scripting, storage, host access) solely to detect tracked sites, run the focus timer, and display the nudge overlay. These permissions are never used to collect or transmit data.
